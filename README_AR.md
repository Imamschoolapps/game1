# شدّ الحبل – النسخة الكرتونية ثلاثية الأبعاد V2

## النشر
ارفع `index.html` و`README_AR.md` إلى جذر مستودع GitHub، ثم من Settings → Pages اختر Deploy from a branch، وحدد `main` و`/(root)` ثم Save.

## ما تتضمنه النسخة
- ملعب كرتوني ثلاثي الأبعاد بكاميرا جانبية ثابتة.
- مدرجات وجمهور ورايات وشخصيات طلابية ثلاثية الأبعاد.
- حبل وعلامة وسطية تتحرك مع الإجابات الصحيحة.
- إدارة الطلاب والأسئلة وقوالب Excel.
- تشكيل فرق، تناوب، مؤقت، سؤال فاصل، وشجرة بطولة.
- حفظ بيانات الطلاب والأسئلة والفرق محلياً في المتصفح.

## ملاحظات
تحتاج المكتبات Three.js وXLSX وخط Cairo إلى اتصال إنترنت لتحميلها من CDN. هذه نسخة تطويرية ينبغي اختبارها قبل الاستخدام الفعلي.
