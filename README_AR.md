# لعبة شدّ الحبل التعليمية

نموذج أولي يعمل في المتصفح باستخدام Three.js وواجهة عربية RTL.

## التشغيل
- افتح `index.html` عبر خادم محلي أو ارفع محتويات المجلد إلى مستودع GitHub عام.
- فعّل GitHub Pages من إعدادات المستودع (Settings → Pages) واختر النشر من الفرع الرئيسي.
- يحتاج مشهد Three.js ومكتبة XLSX إلى اتصال إنترنت لتحميل المكتبات من CDN.

## الوظائف الموجودة
- إدارة الطلاب وإضافة/حذف الطلاب.
- استيراد Excel للطلاب والأسئلة وتنزيل قوالب Excel.
- تشكيل فرق عشوائي أو توزيع بالتناوب.
- إعداد عدد الأسئلة وشرط الفوز والمؤقت.
- واجهة ملعب ثلاثية الأبعاد مع فريق أزرق وأحمر وحبل متحرك.
- تناوب الفريقين والطلاب، احتساب الإجابات، والسؤال الفاصل.
- جدول بطولة وتصدير نتائج Excel.

## ملاحظات
هذا نموذج تصميم أولي يحتاج إلى اختبار شامل قبل استخدامه في حصة فعلية. التخزين محلي على الجهاز والمتصفح، ولا يوجد حالياً حسابات مستخدمين أو مزامنة بين الأجهزة.
